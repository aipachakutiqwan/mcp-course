+----------------------------------------------+

+--------------------------------------+
|            CLIENT-SERVER             |
|            ARCHITECTURE              |
+--------------------------------------+
|                                      |
|  +---------+        +-----------+    |
|  |  HOST   |        |           |    |
|  | (LLM    |        |  SERVER   |    |
|  |  App)   |        |           |    |
|  |         |        |  Provides:|    |
|  | Contains|        |  - Context|    |
|  | CLIENT  |<------>|  - Tools  |    |
|  |         |        |  - Prompts|    |
|  +---------+        +-----------+    |
|                                      |
+--------------------------------------+

+--------------------------------------+
|           PROTOCOL LAYERS            |
+--------------------------------------+
|                                      |
| +------------+    +---------------+  |
| | PROTOCOL   |    | TRANSPORT     |  |
| | LAYER      |    | LAYER         |  |
| |            |    |               |  |
| | - Protocol |    | - Stdio       |  |
| | - Client   |    |   (local)     |  |
| | - Server   |    | - HTTP + SSE  |  |
| |            |    |   (remote)    |  |

|                                      |

|                                      |
+--------------------------------------+

+--------------------------------------+
|           MESSAGE TYPES              |
+--------------------------------------+
|                                      |
| +------------+    +---------------+  |
| | REQUESTS   |    | RESULTS       |  |
| | method     |    | data          |  |
| | params     |    |               |  |
| +------------+    +---------------+  |
|                                      |
| +------------+    +---------------+  |
| | ERRORS     |    | NOTIFICATIONS |  |
| | code       |    | method        |  |
| | message    |    | params        |  |
| | data       |    | (one-way)     |  |
| +------------+    +---------------+  |
|                                      |
+--------------------------------------+

+--------------------------------------+
|        CONNECTION LIFECYCLE          |
+--------------------------------------+
|                                      |
| 1. INITIALIZATION                    |
|    Client → initialize request       |
|    Server → capabilities response    |
|    Client → initialized notification |
|                                      |
| 2. MESSAGE EXCHANGE                  |
|    Request-Response pattern          |
|    Notification pattern              |
|                                      |
| 3. TERMINATION                       |
|    close() method                    |
|    Transport disconnection           |
|    Error conditions                  |
|                                      |
+--------------------------------------+

+--------------------------------------+
|          ERROR HANDLING              |

|                                      |
| Standard JSON-RPC Error Codes:       |

| - MethodNotFound    (-32601)         |
| - InvalidParams     (-32602)         |
| - InternalError     (-32603)         |
|                                      |
| Custom error codes > -32000          |
|                                      |

|                                      |

|    - Message validation              |

|    - Testing                         |
|                                      |
